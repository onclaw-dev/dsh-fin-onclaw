# 市场事件时间线

> 分组：市场行情
> 状态：通过单一 `onclaw_data_interface` 受控桥调用；不是独立注册的 Harness Tool。

规范接口名：`onclaw_get_market_timeline`

调用时令 `interface_name` 等于上述规范接口名，并把下表参数放入 `arguments`。认证由 Onclaw Harness Host 登录会话隐式提供，不得传入 Token、HTTP path、method 或 Header。

普通与 VIP 账户共享本接口的参数、返回字段和公共安全边界；访问判定及额度错误处理见 [访问控制与额度](../访问控制与额度.md)。

## 用途

按日期范围读取题材、资讯、业绩异动和监管生命周期四类统一市场事件；业绩与监管条目包含有界业务摘要和 T 至 T+3 轻量溢价登记。

按一种或多种来源读取市场时间线，用于把题材、资讯、业绩异动、监管事件及其已成熟溢价观察按事件交易日对齐。

## 参数

参数对象必须满足 `additionalProperties: false`，只允许下表字段。

| 参数 | 类型 | 必填 | 可选值 | 说明 |
|---|---|---:|---|---|
| `start_date` | string | 是 | — | YYYY-MM-DD 日期。 |
| `end_date` | string | 是 | — | YYYY-MM-DD 日期。 |
| `source_type` | string | 否 | `topic`、`article`、`performance`、`supervision` | 兼容单选来源；不能与 source_types 同时提供。 |
| `source_types` | array<string> | 否 | `topic`、`article`、`performance`、`supervision` | 多选来源，去重后最多 4 项；不能与 source_type 同时提供。省略两个来源参数时默认全选四类。 |
| `topic_id` | string | 否 | — | 可选题材 ID，最多 120 字符。 |
| `limit` | integer | 否 | — | 1..1000，默认 500。 |

### 最小参数骨架

```json
{
  "start_date": "<start_date>",
  "end_date": "<end_date>"
}
```

占位符必须在真正实现或 Inspector 测试前替换为符合说明的值；不要把占位符作为真实参数发送。

## 输出与处理

### 验证来源

- 实际请求：HTTP 401。
- 契约来源：TimelineModule.read_unified + TimelineEventProjection + EventPremiumRegistration.to_dict。
- 只读测试请求返回 HTTP 401（认证或统一访问策略阻止取得业务样本）；以下业务结构来自服务、模块及前端消费契约。
- 数据库模型只用于核对已下发字段的标量类型和含义；未被 service/module 序列化的列不在本契约中。

### 响应外壳

| 路径 | 类型 | 枚举/固定值 | 说明 |
|---|---|---|---|
| `code` | integer | — | 业务状态码；成功为 `200`。 |

### 结构重建

- 先由 HTTP 客户端处理可能存在的 gzip，再解析 JSON；不要对已经得到的对象再次解压。
- 只在上述明确标为 `TableData` 的路径执行 `columns[i] -> rows[*][i]` 映射。
- Topic 树、分页对象、运行态对象和动态键映射保持原有对象/数组结构，不要递归转换为 DataFrame。
- 完整规则见 [传输与结构重建](../传输与结构重建.md)。

- 建议超时上限：60000 ms；实际调用仍应支持取消。
- 原始长表、Window 或 Runtime 结果应先经过范围裁剪、关联或特征处理，再进入最终 LLM 判断。
- 空结果不自动代表失败，应结合交易日、筛选条件、权限和数据可用性判断。

## 编排建议

1. 在流程中明确该接口的参数来源，而不是让最终判断 LLM 临时猜测参数。
2. 记录日期口径、股票范围、题材或报告期等关键坐标。
3. 将接口结果传给确定性筛选或 Python 特征节点；只把有界证据交给判断节点。
4. 保留数据状态、revision、coverage、warnings 和缺失信息。

## 注意事项

- 省略 source_type/source_types 时默认返回四类来源；多选使用 source_types，且不能与兼容参数 source_type 同时提供。
- 业绩时间线只纳入 T 日绝对涨跌幅严格大于 8%，或明确涨停、跌停、炸板的股票；不要在模型侧改变该入选口径。
- daily_pct_chg 是观察日自身涨跌幅，premium_pct 是相对 T 日收盘的累计溢价；二者不得混用。
- 参数对象是闭合的；未声明字段必须视为错误，不能静默转发。
- 返回值保持现有 Onclaw BaseResponse 及接口数据结构，空值、缺失字段和警告不得自行补零。
